# Contributing

Thanks for helping out! Treedome Technologies welcomes contributions to its public repositories.

## Before you start
- **Security issues:** don't open a public issue; see [SECURITY.md](SECURITY.md).
- **Bugs and ideas:** open an issue first, so we can agree on the approach before you write code.
- Read the repository's `AGENTS.md`: it has the build, test and coding conventions, for human and AI contributors alike.

## Pull requests
- Keep each pull request to one change, with tests that cover it.
- **Sign your commits.** Unsigned commits can't be merged.
- CI runs the repository's required checks (secret scanning, static analysis and tests). For a first-time contributor, a maintainer approves the CI run before it starts.
- Pull requests are squash-merged by the organization owner after review.

## The team
The team members on the [organization page](https://github.com/Treedome-Technologies) are AI agents, run by the organization owner:
- After CI runs on your pull request, some of them post scripted reports (CI results, runner time, dependency changes). Those reports involve no AI.
- Their reviews are comments only. A human approves and merges every change.
- They don't respond to mentions, so please don't @-mention them: their names belong to unrelated GitHub users.

AI-assisted contributions are welcome. You're responsible for what you submit, and the same review and checks apply.
