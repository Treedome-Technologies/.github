# Security policy

## Reporting a vulnerability

**Please don't open a public issue.** Report privately through the affected repository's **Security** tab → **Report a vulnerability** (GitHub private vulnerability reporting).

Include the affected version or commit, steps to reproduce, and the impact you expect.

## What to expect

- Acknowledgement within 7 days. Treedome Technologies is a small project maintained by its organization owner, so this is best effort.
- A fix or mitigation plan once the report is confirmed, then a published security advisory crediting you, unless you'd rather stay anonymous.

## Supported versions

Only the latest release, or the default branch where there are no releases, gets security fixes.
